# 纸间 · 读一点旧时光

<img src="public/icon-192-v2.png" width="96" alt="纸间图标">

纸白与赭红之间，随手翻读诗词、古文和旧事。一个可以独立部署的个人阅读网站，附带 **12 则默认示例**。每位使用者配置自己的 AI API 密钥，内容、收藏、已读和费用都保存在自己的实例中。

## 先看这里

- **不填 AI 密钥也能运行**：先读默认内容、体验分类、搜索、收藏与已读。
- **每日更新默认关闭**：只有手动生成，或明确开启定时更新后，才会调用你的 AI 服务。
- **生成内容默认是草稿**：核对原典与解读后，再点“确认发布”。
- **密钥不放在网页中**：只在你自己的服务器环境变量或本地 `.env` 中配置。
- **这里没有作者的自用实例**：没有作者的账号、部署标识、数据库、阅读记录或每日任务。
- **这是单人自用模板**：同一实例用一个独立访问密码，手机与电脑共用记录。它不是多人注册平台，也不使用作者的 ChatGPT 登录。

## 可以做什么

- 分类、搜索、随机翻阅、收藏、手动已读/未读；已读从推荐和随机中排除。
- 阅读外观：随站提供小薇宋和文楷精简字库，另有系统黑体；14至30px字号、文字和背景颜色，四套预设及恢复默认。首次选择网页字体时会显示加载状态，加载后自动换字形；少量生僻字会回退至设备字体。设置保存在当前设备。
- 并行加载内容和阅读记录，不让一个慢请求阻塞另一个；默认示例可先显示，个人内容缓存只在服务器确认对应实例登录后恢复。
- 同一实例中跨设备同步记录；断网时暂存标记，恢复后重试。网页内容目前没有完整离线缓存。
- 从维基文库抓取公开原典，再调用你配置的 Chat Completions 服务生成短标题、白话和阅读札记。
- 检查引文是否实际出现在抓取文本中；按引文去重；保留出处链接。
- 草稿预览、确认发布、移出草稿、备份数据。
- 可选每日定时更新，每日最多运行一次；失败不会无限自动重复收费调用。

## 第一次使用 GitHub

在本项目页面点 **Use this template → Create a new repository**，为自己的项目取一个名字。初学者建议先选 **Private（私有）**。

复制完成后，你拥有的是独立仓库，不会连接作者的数据。接下来下载自己的代码，或部署到自己选择的托管平台。GitHub 仓库负责放代码；**GitHub Pages 不能运行这里的 Node 服务端**，也不能安全地代替本程序保存 AI 密钥。

详细步骤见 [GitHub 新手分享指南](docs/GITHUB.md)。

## 本机先试用

需要 **Node.js 24 或更新版本**。程序没有第三方运行依赖，不用先安装数据库。

1. 下载并解压项目。
2. 在项目文件夹打开终端。
3. 运行：

   ```bash
   npm start
   ```

4. 在浏览器打开 `http://127.0.0.1:3000`。

如果你的环境只有 `node` 命令，也可以运行 `node --env-file-if-exists=.env src/server.js`。

默认只监听本机，显示12则示例，AI 没有配置时“抓取并生成”不可用。第一次运行生成的 `data/` 是你的私人数据，不要上传。

## 使用自己的 AI 密钥

把 `.env.example` 复制为 `.env`，填入：

```dotenv
AI_BASE_URL=你的供应商官方兼容API地址
AI_MODEL=你要使用的模型名称
AI_API_KEY=你自己的API密钥
```

`AI_BASE_URL` 是 `/chat/completions` 之前的部分。例如供应商文档写 `https://api.deepseek.com/v1/chat/completions`，这里填 `https://api.deepseek.com/v1`。不同供应商的地址、模型名、兼容程度与计费各不相同，请以各自官方说明为准。不要填 ChatGPT 密码、浏览器登录 token 或 GitHub token。

重新启动后，点网页的 **内容管理 → 抓取并生成**。原典先由程序获取，随后发送给你配置的 AI 服务；**密钥只发送到你填写的 AI 服务地址**。源码、浏览器和备份不需要包含密钥。

原典抓取不需要 AI 密钥；解读生成会使用 AI 供应商的 API 配额，可能产生费用。ChatGPT 订阅不等于其他服务的 API 余额。

## 手机、电脑共用

把程序部署到自己的持续运行服务器，配置以下环境变量：

```dotenv
HOST=0.0.0.0
APP_PASSWORD=你自己设置的至少12字符独立访问密码
PUBLIC_URL=https://你自己的部署域名
DATA_DIR=/app/data
```

两台设备访问同一个部署地址、使用同一个实例密码登录，即可同步。密码通过 HttpOnly 会话 Cookie 使用，不会写入浏览器本地存储。修改访问密码会使旧会话失效。

**对外部署需 HTTPS，并给 `DATA_DIR` 配置持久磁盘或持久卷。** 临时文件系统可能在重启后丢失内容。单实例只运行一个 Node 进程；不支持多个进程同时操作同一个 JSON 数据文件。

见 [部署指南](docs/DEPLOYMENT.md)。

## 每日更新（可选）

在自己的环境中明确设置：

```dotenv
AUTO_UPDATE_ENABLED=true
DAILY_COUNT=4
UPDATE_HOUR=8
UPDATE_TIMEZONE=Asia/Shanghai
AUTO_PUBLISH=false
```

服务器每分钟检查时间，到当天设定时刻后运行一次。需要进程保持在线；如果平台休眠，唤醒后才会检查，并不会补跑之前每一天。更新失败或重启不会在同一天不断重试，避免意外的连续付费调用。

默认产生草稿，等待核对。`AUTO_PUBLISH=true` 会把通过原文比对的内容直接发布：**原文比对不能验证所有历史细节、作者归属、翻译与解读**，请自行评估是否开启。

## 修改默认内容

编辑 `public/seed.json`，每则包含：

```json
{
  "id": 101,
  "cat": "诗词",
  "title": "你的短标题",
  "quote": "核对过的古典原句",
  "author": "作者",
  "era": "时代",
  "work": "篇名",
  "summary": "卡片上的简短引子",
  "plain": "自己的白话表达",
  "detail": "简短的文字趣味或背景说明",
  "source": "https://支持这则内容的原文页面",
  "sourceLabel": "出处名称",
  "original": true
}
```

`cat` 使用“诗词”“古文”“旧事”；`id` 保持唯一，发布后避免随意更换，以免影响阅读标记。附带的 `src/source-catalog.json` 是抓取候选篇名，不是作者的私人内容库；候选不足时程序继续从维基文库分类中寻找篇目。

## 文件与隐私

| 文件或目录 | 用途 | 上传 GitHub？ |
| --- | --- | --- |
| `public/seed.json` | 默认示例内容 | 可以 |
| `.env.example` | 不含真实值的配置说明 | 可以 |
| `.env` | 自己的密码和 AI 密钥 | 不可以 |
| `data/` | 自己生成的内容、阅读记录与会话密钥 | 不可以 |
| `backups/` | 自己导出的备份 | 不可以 |

`.gitignore` 和 `.dockerignore` 已设置。它们不能清除已经提交过的敏感历史；若泄露真实密钥，应先到供应商处撤销/轮换密钥。

## 检查与测试

```bash
npm test
npm run check
```

测试使用模拟 AI 响应，覆盖登录、鉴权、跨设备记录合并、草稿入库、重复过滤、引文检查和定时任务。**不会花费真实 AI 额度**，也不代表每家供应商都已实测。

外观和内容缓存不包含AI密钥。外观选择按设备保存，不会跟随阅读记录跨设备同步。缓存不等于完整离线网页；首次访问和登录仍需网络。退出实例会移除当前实例的本机内容缓存。

网页字体按需从同一个实例加载并缓存，不依赖第三方字体CDN。字体是重命名的OFL衍生子集，来源、修改说明及许可证见 `public/FONT-NOTICES.md`、`public/font-song-OFL.txt` 和 `public/font-wen-OFL.txt`；代码MIT许可不覆盖字体的OFL许可。

## 备份与恢复

内容管理里的“备份我的内容与记录”导出个人数据，不含 AI 密钥、访问密码或会话密钥。请自行保存在私人位置。

恢复时先停止程序，再运行：

```bash
node scripts/restore-backup.mjs /你的私人备份文件路径.json
```

脚本会先保存当前数据副本，再恢复内容；恢复后重新登录。它读取 `.env` 中的 `DATA_DIR` 时，请使用 `node --env-file-if-exists=.env scripts/restore-backup.mjs ...`。
